# Daily Growth content

Daily SEO publications live in this directory as isolated bilingual JSON files.

Naming convention:

- `YYYY-MM-DD-dayNN-topic.landings.json`
- `YYYY-MM-DD-dayNN-topic.articles.json`

Each publication should add new files rather than rewrite previous days. The Growth content loader, editorial contract and production verifier discover these files automatically.

Editorial floor for new daily content:

- landing: at least 900 editorial words per locale;
- article: at least 1,200 editorial words per locale.

Each landing/article pair must keep unique keys and slugs, ES/EN parity, reciprocal related keys, canonical-safe slugs and substantive useful content. Avoid keyword stuffing: cover the search intent through useful sections, semantic variants, FAQs, workflows, metrics, examples and operational constraints.
